<a id="october-28-2025"></a>
### 2025. 10. 28. { #october-28-2025 }
<a id="october-28-2025-feature-updates"></a>
#### 機能改善・変更
* [Console/API] 広告送信時における080受信拒否番号の有効性検証ロジックを緩和
  * 広告を送信する際に、080受信拒否番号の途中に「-」を挿入しても、正常に送信されるように変更されました。
* [ETC] 通知管理 - 月間送信量制限の通知を追加
  * 設定された月間送信量制限値の70%、90%、100%に到達するたびに、自動で通知を受け取ることができます。
  * **プロジェクトダッシュボード > 通知管理**で設定可能です。

<a id="october-28-2025-bug-fixes"></a>
#### バグ修正
* [API] 統計照会バグ修正
  * 統計照会時にデータ検索範囲を狭く設定した場合、データが2倍に照会されるバグが修正されました。

### 2025. 06. 24. { #june-24-2025 }
<a id="june-24-2025-feature-updates"></a>
#### 機能改善・変更
* [Console/API]国際送信統計改善
    * 国際送信統計の送信件数イベント収集時間基準が送信成功時間基準に変更されました。

<a id="march-4-2025"></a>
### 2025. 03. 04. { #march-4-2025 }
<a id="march-4-2025-feature-updates"></a>
#### 機能改善・変更
* [Console/API]国際送信の受信結果がDLR結果を反映するように改善されました。
    * 受信成功はDLR状態がDELIVERED状態であることを意味します。
    * 受信失敗は、DLRの状態がEXPIRED、FAILED、REJECTED、UNKNOWNの状態であることを意味します。
    * 国際送信結果が受信失敗の場合、受信結果コードは次の文書を参照してください。
        * [[受信結果コード](../error-code/#_1)]
* [Console]国際送信統計改善
    * 国際送信統計分類にメッセージタイプ照会フィルタを追加しました。
    * 国際送信統計分類に受信イベントが追加されました。
    * 統計イベントの詳細については、 [[統計 > 統計照会](../console-guide/#_42)]を参照してください。
* [API]国際送信統計API改善
    * 国際送信統計APIに受信イベントを追加しました。
    * 詳細については、 [[API v3.0ガイド > 統計検索 - 国際送信](../api-guide/#-_2)]を参照してください。

<a id="march-4-2025-added-features"></a>
#### 機能追加
* [Console/API]送信リスト照会時に国内/国際区分フィルタ、国コードフィルタ追加
    * SMSリクエスト別照会、大量SMS送信照会、タグSMS送信照会コンソール画面に国内/国際区分フィルタ、国コードフィルタを追加しました。
    * 全てのバージョンのSMS送信リスト検索、長文MMS送信リスト検索、予約送信リスト検索、認証用SMS送信リスト検索、大量送信受信者リスト検索、タグ送信受信者リスト検索APIのQuery ParameterにreceiverRegion、countryCodeフィールドを追加しました。
    * 詳細については、[[API v3.0ガイド](../api-guide)], [[API v2.4ガイド](../api-guide-v2.4)], [[API v2.3ガイド](../api-guide-v2.3)], [[API v2.2ガイド](../api-guide-v2.2)]を参照してください。

<a id="march-4-2025-bug-fixes"></a>
#### バグ修正
* [API]国際送信統計APIバグ修正
    * 国際送信統計APIでコンバージョン率収集リクエスト送信成功数、コンバージョン数イベントが表示されないバグを修正しました。
