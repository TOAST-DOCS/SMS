<a id="may-28-2024"></a>
### 2024. 05. 28. { #may-28-2024 }
<a id="may-28-2024-added-features"></a>
#### 機能追加
* [Console/API]国際SMS送信コンバージョン機能追加
    * 送信API変更
        * v3.0 SMS送信、 v3.0認証SMS送信、 v3.0広告SMS送信時にコンバージョン率収集リクエストを表すuseConversionフィールドが追加されました。
        * このフィールドを利用したコンバージョン率収集リクエストは、国際送信リクエストに対してのみ有効です。
    * コンバージョンAPIを追加
        * コンバージョン率収集リクエストに対してコンバージョンを試みるAPIが追加されました。
    * サービス設定 > 国際SMS送信設定タブにコンバージョン率によるブロックと通知設定を追加しました。
        * 国際SMS送信設定画面にコンバージョン率に基づく送信ブロックと通知機能が追加されました。
        * コンバージョン率に基づく送信ブロックを適用するブロック国設定機能が追加されました。
    * 詳細については、 [[国際SMS送信ポリシー > 国際SMSコンバージョン率に基づく送信ブロック](../international-sending-policy/#sms_2)]を参照してください。
* [Console]コンバージョン率に基づく送信ブロックのWebフックを追加
    * コンバージョン率に基づく送信ブロックが発生した場合、Webフックを受け取ることができます。
    * Webフックは特定国家送信信がコンバージョン率によってブロックされた場合に発生します。
    * 詳細については、 [[Webhookガイド](../webhook/#hooks)]を参照してください。
